# Historical TauCeti port provenance

The elliptic-curve adapters import the published TauCeti package directly.
The [build guide](../../../docs/BUILD.md) gives the active commit and cache instructions.

Before the package migration, the project carried excerpts of 53 Lean modules.
[PROVENANCE.json](PROVENANCE.json) records the source revisions, file hashes,
and adaptations for those excerpts. Its local paths refer to the
[last pre-migration source tree](https://github.com/khwilson/verified-lcalc/tree/3f0545dc083726dfc2e6e76ff30e45e472b83df0/VerifiedLcalc/Upstream/TauCeti).
[NOTICE.md](NOTICE.md) records the attribution for the minimal-model and global
minimality excerpts. The [Apache license](../../../LICENSES/TauCeti-Apache-2.0.txt)
accompanies these records.
